# Project language

All project-authored source code, contract text, comments, UI copy, error messages,
logs, scripts, generated reports, documentation, and filenames must use English.
Use English document language metadata and left-to-right layouts. Do not add
Persian-language text or translations to this project.

Preserve economic rules, addresses, security checks, and transaction behavior
when editing language. Numeric input normalization may accept Unicode digits and
separators, but write those characters as Unicode escapes in source and tests.
Do not modify user-generated content or immutable blockchain history to enforce
this policy. Do not rewrite Git history or change generated contract bytecode
solely for a language cleanup.
